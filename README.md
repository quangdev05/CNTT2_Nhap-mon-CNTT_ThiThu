# Website Văn Phòng Phẩm

## Giới thiệu

- Trang thông tin về **Văn phòng phẩm.**
- Đăng ký _NHẬN THÔNG TIN_ ngay.

## Cấu trúc thư mục

| Thư mục | Nội Dung                          |
| ------- | --------------------------------- |
| data    | Chứa dữ liệu người dùng, đơn hàng |
| media   | Chứa các file hình ảnh            |
| docs    | Chứa dữ liệu nhập hàng, hàng hoá  |

## Liệt kê nội dung dự án

```shell
gci -R -Force
```

## Công việc

- [x] Tạo thư mục dự án
- [ ] Nhập hàng
